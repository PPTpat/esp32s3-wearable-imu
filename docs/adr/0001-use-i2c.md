# ADR 0001: Use I2C to connect the LSM6DSOX

## Status
Accepted

## Context
Target ODR for human motion is 104-416 Hz with accelerometer and gyroscope
batched in the FIFO (7 bytes per word, 2 words per sample period).
At 416 Hz this is about 5.8 kB/s; I2C at 400 kHz carries about 40 kB/s.

## Decision
Use I2C (address 0x6A). The driver talks to `hal::IBus`, so SPI can be added
as another implementation without touching the driver.

## Consequences
- Two wires, simple wiring.
- Headroom is limited: ODR above about 833 Hz would need SPI.
- Bus load must be measured (see roadmap v0.6).
